# PrintechFixcare

Aplicación web desarrollada con **HTML, CSS y JavaScript** para registrar, buscar y consultar soluciones de incidencias técnicas, códigos de error y diagnósticos de equipos de impresión.

## Funcionalidades actuales (Fase 1 — Frontend)
- Búsqueda instantánea por código de error, modelo o síntoma.
- Filtro por categoría técnica.
- Creación, edición, consulta detallada y eliminación de incidencias (CRUD).
- Persistencia local mediante `localStorage`.
- Copiar pasos de solución al portapapeles y exportar/importar respaldos en JSON.

## Próximas fases planeadas
- **Fase 2:** Backend y base de datos para persistencia centralizada e historial de consultas.
- **Fase 3:** Integración de catálogo técnico/HP y asistente de diagnóstico asistido por IA.
